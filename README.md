# Finance Notes｜金融知識筆記庫

## 一、專案介紹
Finance Notes 是一個以繁體中文呈現的金融知識網站，主要整理銀行、證券、金融法規及金融證照相關知識，讓使用者能透過簡單的分類與搜尋功能，快速找到需要的資訊。

## 二、設計目的
希望將平常在學校接觸到的金融知識整理成容易閱讀的內容，讓金融初學者也能快速理解基本觀念。

## 三、網站功能
- 金融知識分類瀏覽
- 關鍵字搜尋
- 文章摘要及完整內容閱讀
- 支援電腦及手機瀏覽

## 四、知識分類
1. 銀行知識
2. 證券知識
3. 金融法規
4. 金融證照

## 五、使用技術
- HTML：建立網站架構
- CSS：設計網站外觀
- JavaScript：製作搜尋、分類及文章互動功能

## 六、檔案說明
- index.html：網站首頁
- styles.css：網站樣式
- app.js：網站互動功能
- notes.js：金融知識文章資料
- AGENTS.md：AI 開發規則
- README.md：專案說明文件

## 七、未來規劃
未來希望持續增加金融相關文章，補充更多實務案例，讓網站成為可以持續更新的金融知識筆記庫。
